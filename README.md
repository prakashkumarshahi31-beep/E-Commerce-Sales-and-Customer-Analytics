# E-Commerce-Sales-and-Customer-Analytics
An end-to-end E-commerce Sales and Customer Analytics project focused on analyzing sales performance, customer behavior, and business insights using SQL and data visualization


## 📌 Project Overview

This project focuses on analyzing e-commerce sales and customer data to understand sales performance, customer purchasing behavior, and business trends.

The objective is to transform sales data into meaningful insights that help businesses make data-driven decisions using SQL and Microsoft Power BI.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify top-performing products and categories.
- Understand customer purchasing behavior.
- Analyze city-wise sales performance.
- Identify high-value customers.
- Answer business questions using SQL.
- Present business insights through data visualization.
- Provide actionable recommendations based on analysis.

## 🛠️ Tools and Technologies

- **MySQL:** Database management and querying.
- **SQL:** Data analysis, aggregation, joins, subqueries, and CTEs.
- **Microsoft Power BI:** Data visualization and dashboard development.
- **Data Analytics:** Business problem-solving and insight generation.

## 📂 Dataset

The project uses an e-commerce sales and customer analytics dataset containing sales and customer-related information.

**Dataset file:** `E-Commerce data.zip`

The compressed dataset is available in this repository.
